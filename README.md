# Muse 定时发信

在 [muse.ai](https://muse.ai) 网页端，把文本消息按计划发送到**指定的已有会话**（`/thread/<id>`）。

muse2api 的 `/v1/chat/completions` 是无状态的（每次都会新建会话），只有网页端才能真正往某个已有会话里发消息，所以这个脚本走的是浏览器自动化。

## 功能

- 按「每隔 N 分钟 / 每天 HH:MM / 指定时间一次」发送
- 任务列表显示会话标题 + 会话 ID，标题自动从左侧会话栏抓取，点击标题可手动修改
- 多标签页互斥：同一个任务同一时间只在一个标签页里执行
- 发送前校验当前页面、跳过进行中的生成、不覆盖已有草稿
- 发送后确认：新消息气泡出现 / 生成开始 / 输入框被清空，三重判据
- 失败自动重试（5 分钟后），连续失败回落到原计划
- 左下角悬浮球可拖动，位置会记住；单击打开面板

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开 [muse-scheduler.user.js](./muse-scheduler.user.js)，点「Raw」，Tampermonkey 会自动弹出安装页
3. 或新建脚本后把文件内容整体粘贴进去

## 使用

1. 登录 muse.ai，打开目标会话（地址形如 `https://muse.ai/thread/xxxxxxxx-...`）
2. 点左下角 ⏰ 悬浮球打开面板
3. 填会话标题（或留空自动抓取）、会话 ID、消息内容，选周期，保存
4. 到点后脚本会自动切到该会话并发送

> 需要保持 muse.ai 的标签页打开。浏览器会节流后台标签页的定时器，建议把该标签页单独放一个窗口，或至少不要关闭。

## 说明

- 会话 ID 就是地址里 `/thread/` 后面那段
- 面板里的「复位」用于清理卡住的发送锁；「立即发送」会跳过计划直接执行一次
- 诊断菜单：`🧪 复制发送诊断信息`（输入框/按钮结构）、`🔍 复制标题诊断信息`（会话栏结构）
